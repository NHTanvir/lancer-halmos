# lancer-halmos

Rust clone of `halmos`. Part of the Lancer ecosystem — a complete 2026 AI-era bug bounty toolkit.

🚧 **In development.**

## Build

### Windows
Double-click `build.bat` or run from cmd:
```
build.bat
```
Output: `build\lancer-halmos.exe`

For a packaged dist build:
```
build-windows.bat
```
Output: `dist\lancer-halmos-windows-x86_64\bin\lancer-halmos.exe`

### Linux / macOS
```bash
./build-linux.sh
```
Output: `build/lancer-halmos`

### Requirements
- [Rust / Cargo](https://rustup.rs)
- (Windows) Visual C++ Build Tools 2019/2022
